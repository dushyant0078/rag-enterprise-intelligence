# compose-spec-schema.json

Vendored from the official Compose Specification repository:
https://github.com/compose-spec/compose-spec/blob/master/schema/compose-spec.json

Downloaded for Milestone 12's `scripts/validate_deployment_artifacts.sh`, which validates
`docker-compose.yml` against it without needing network access at validation time. Re-fetch
periodically from the URL above if the Compose Specification adds fields this project's
`docker-compose.yml` starts using.
