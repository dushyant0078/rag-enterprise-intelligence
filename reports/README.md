# reports/

Generated benchmark and evaluation output. Only Markdown summaries are
committed — raw JSON run data is regenerated by re-running the matching
script (`scripts/compare_chunking_strategies.py`,
`scripts/build_index_and_compare_retrieval.py`,
`scripts/compare_reranking.py`,
`scripts/run_conversational_pipeline_demo.py`,
`scripts/run_evaluation_framework.py`), not treated as a durable artifact.

- **`final_benchmark_report.md`** (Milestone 14) — the consolidated final
  report: test suite stats, real evaluation-framework numbers, a real live
  load test, and an 18-bug retrospective across all 13 build milestones.
- `milestone4_chunking_comparison.md` — 7 chunking strategies compared
- `milestone5_retrieval_comparison.md` — retrieval strategy comparison
- `milestone6_reranking_comparison.md` — what reranking fixed, and why
- `milestone7_conversational_pipeline_demo.md` — full pipeline demo results
- `milestone8_evaluation_report.md` — the evaluation framework's own report
  (re-generated fresh each run; current numbers also folded into
  `final_benchmark_report.md`)
